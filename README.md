# Stevens Parking — Project Feedback Site

One-page site with our story, project video, and a link to our feedback survey.

## Edit before publishing
Open `script.js` and fill in the three values at the top:

- `VIDEO_URL` — YouTube, Google Drive, Vimeo link, or an `.mp4` file in this repo
- `SURVEY_URL` — Google Forms / Microsoft Forms / etc. link
- `TEAM` — team member names

The story text is in `index.html` inside the `#story` section (look for `✏️ EDIT`).

> Google Drive videos must be shared as "Anyone with the link can view" or they won't play.

## Host on GitHub Pages
1. Create a new public repo on GitHub and upload `index.html`, `style.css`, `script.js`, `video.mp4` and `poster.jpg`, all in the root folder.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
